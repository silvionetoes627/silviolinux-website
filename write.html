Mídia de instalação

Como gravar o SilvioLinux no disco

O SilvioLinux foi planejado para iniciar diretamente de uma imagem de sistema, sem um instalador pesado e sem exigir uma instalação manual tradicional.

Formatos de imagem

WIC (.wic) e IMG (.img). A imagem deverá conter o RootFS (sistema de arquivos raiz) e o Kernel Linux, além das partições e metadados necessários para inicialização.

Como funciona

  1. Baixe uma imagem compatível com seu dispositivo.
  2. Identifique corretamente o cartão de memória, pendrive, HD externo USB ou SSD externo.
  3. Grave o arquivo WIC ou IMG com uma ferramenta de gravação de imagens confiável.
  4. Ejete o dispositivo com segurança e configure o computador/placa para inicializar por ele.
Atenção: gravar uma imagem sobrescreve os dados do dispositivo selecionado. Confira cuidadosamente o destino antes de iniciar.

Onde gravar

  • Cartão de memória.
  • Pendrive USB.
  • HD externo USB 3.0.
  • SSD externo USB 2.0 ou USB 3.0.

Velocidade USB

Em condições equivalentes, USB 3.0 costuma oferecer gravação mais rápida que USB 2.0. Em USB 2.0, o processo tende a demorar mais. A velocidade real também depende do dispositivo, da porta, do controlador, do arquivo e da ferramenta utilizada. Um SSD USB 2.0 pode ser limitado pela interface, mesmo sendo um SSD.

Kernel customizado

O projeto planeja manter variantes de kernel identificadas como linux-silvio-slts e linux-silvio-lts, alinhadas às linhas de suporte correspondentes.
