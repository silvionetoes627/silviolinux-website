Observações:
1. Datas e bases Yocto futuras são roadmap planejado, não releases confirmados.
2. EOL calculado para a tabela: SLTS = 8 anos gratuitos e horizonte ESLTS = 20 anos totais; LTS = 4 anos. São referências escolhidas dentro das faixas solicitadas.
3. A linha 39.0 foi colocada no grupo systemd para resolver a sobreposição dos intervalos informados.
4. Os requisitos de 16 MB/Pentium 75 MHz são metas experimentais muito restritivas; validar em hardware real.
5. Não foram incluídos binários WIC/IMG fictícios. Links de releases apontam ao GitHub informado.
6. A tabela preserva as datas fornecidas, inclusive os intervalos não regulares de 2046 em diante.
