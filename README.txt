SILVIOLINUX — SITE ESTÁTICO (HTML + CSS PURO)
================================================

Abra index.html no navegador. O site não utiliza JavaScript, frameworks,
fontes externas ou dependências de build.

Páginas:
- index.html
- download_sourcecode.html
- changelog.html
- download_images_precompileds.html
- compilation_guide.html
- status_silviolinux_versions.html
- wiki.html
- docs.html

Personalização:
- Logo vetorial: assets/logo-silviolinux.svg
- Estilos: assets/style.css
- Tabela completa: status_silviolinux_versions.html

Notas sobre o roadmap:
- As datas e versões Yocto futuras são projeções fornecidas para o planejamento.
- EOL calculado como 4 anos após lançamento para LTS e 7 meses para Non-LTS.
- Requisitos de hardware são metas indicativas uniformes, não garantias de suporte
  em todos os futuros releases do Yocto.
- Codenames das versões 36 a 70 permanecem "A definir".
- "Zenith" aparece nas versões 5 e 32 conforme a lista fornecida.
- A sequência de datas das versões 46–48 e algumas datas tardias foi mantida
  exatamente como fornecida, mesmo quando foge do padrão anterior.

Para publicar:
1. Hospede a pasta inteira em um servidor web estático.
2. Configure HTTPS e domínio.
3. Substitua URLs de repositório de exemplo pelas URLs oficiais verificadas.
4. Atualize a página de downloads somente quando os binários estiverem publicados.
