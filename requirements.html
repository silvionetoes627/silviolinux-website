Requisitos de hardware

O roadmap prevê três perfis de plataforma. Os números abaixo são metas mínimas históricas/experimentais e devem ser validados com imagens reais.

Nota técnica: 16 MB de RAM e Pentium clássico são metas extremamente restritivas para uma distribuição construída com Yocto. A viabilidade depende de uma imagem muito enxuta, kernel, drivers e serviços selecionados. Não são requisitos garantidos para todas as edições, especialmente Desktop, Gaming e Mobile.

Seis edições

Desktop Edition

Ambiente gráfico e aplicações de uso diário.

Base Edition

Sistema base para personalização e criação de produtos.

Minimal Edition

Imagem reduzida, poucos serviços e baixo consumo.

Server Edition

Serviços de rede e infraestrutura sem interface gráfica por padrão.

Gaming Edition

Pacotes e ajustes para jogos, conforme suporte de hardware.

Mobile Edition

Imagem para dispositivos móveis e placas suportadas.
