Guia de compilação

Fluxo de referência para construir imagens SilvioLinux com o Yocto Project e a camada meta-silviolinux.

1. Preparar o ambiente

Use uma distribuição Linux suportada pela versão do Yocto escolhida. Instale os pacotes de dependência listados na documentação oficial do Yocto para seu sistema hospedeiro.

2. Obter a camada

git clone -b aurora https://github.com/silvionetoes627/meta-silviolinux.git
cd meta-silviolinux

3. Inicializar o ambiente

O comando exato depende do layout do repositório, do manifest e da versão do Yocto. Em um projeto baseado em oe-init-build-env, o fluxo costuma seguir este padrão:

source oe-init-build-env build

4. Configurar e compilar

Configure conf/local.conf e conf/bblayers.conf de acordo com a máquina-alvo, distro e camadas realmente disponíveis. Depois, execute o alvo de imagem definido pelo projeto:

bitbake NOME-DA-IMAGEM
Não copie o comando de exemplo sem conferir: NOME-DA-IMAGEM é um marcador. O nome real da receita deve ser confirmado no repositório. O pacote deste site não presume receitas, branches auxiliares ou configurações que não foram fornecidas.

5. Artefatos

Quando habilitados na configuração da máquina, os builds podem produzir imagens como WIC e/ou IMG. Verifique o diretório de deploy da compilação e a documentação da placa-alvo.
