Guia de compilação

Fluxo de referência para preparar o ambiente e construir uma imagem com o Yocto Project.

Os comandos abaixo são um roteiro genérico. Use a documentação e os scripts do repositório para confirmar dependências, releases suportadas, nomes de targets e configuração da máquina-alvo.

1. Preparar o host

Use uma distribuição Linux x86-64 suportada pelo Yocto correspondente. Instale compilador, make, Git, Python, utilitários de arquivo e demais dependências listadas na documentação da versão escolhida.

2. Clonar o repositório

git clone -b aurora https://github.com/silvionetoes627/meta-silviolinux.git
cd meta-silviolinux

3. Inicializar o ambiente

Em projetos Yocto, normalmente é necessário inicializar o ambiente de build por meio do script fornecido pela camada de distribuição ou pelo Poky. O nome exato depende da estrutura do repositório.

# Exemplo genérico; confira o caminho real no repositório
source oe-init-build-env build

4. Configurar e compilar

Defina a máquina-alvo e as opções da distribuição nos arquivos de configuração indicados pelo projeto. Em seguida, execute o BitBake para o target documentado.

# Exemplo genérico; substitua pelo target real
bitbake nome-da-imagem

5. Localizar os artefatos

As imagens normalmente ficam em um diretório de deploy dentro da árvore de build, organizado por máquina e arquitetura. Consulte os logs e os manifests para identificar os arquivos corretos.
