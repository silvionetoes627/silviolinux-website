Guia de compilação

Fluxo de referência para preparar um ambiente Yocto e iniciar a construção da imagem SilvioLinux.

Antes de começar

Use a documentação oficial da versão Yocto escolhida. Os comandos exatos, dependências do host e nomes de targets podem mudar entre releases. O exemplo abaixo é um esqueleto e pressupõe que a camada do SilvioLinux já exista.

1. Preparar o host

Utilize uma distribuição Linux suportada pelo Yocto, instale as dependências indicadas no manual da versão e reserve espaço amplo em disco. Compilações completas podem consumir dezenas de gigabytes.

sudo apt update
sudo apt install git diffstat chrpath cpio python3   python3-pip python3-pexpect xz-utils file   gcc g++ make socat unzip wget

2. Obter o código

git clone https://git.yoctoproject.org/poky
git clone https://codeberg.org/SilvioRamalhoNeto/meta-silviolinux.git

Confira os branches/tags compatíveis entre Poky, layers e BitBake antes de compilar.

3. Inicializar o ambiente

cd poky
source oe-init-build-env build-silviolinux

4. Configurar as camadas

Adicione o caminho da camada meta-silviolinux a conf/bblayers.conf e configure máquina, distribuição e recursos em conf/local.conf e nos arquivos de distro.

# Exemplo conceitual — ajuste os caminhos e nomes reais
BBLAYERS += "${TOPDIR}/../meta-silviolinux"
DISTRO = "silviolinux"
MACHINE = "qemux86"

5. Executar a compilação

bitbake core-image-minimal

Quando o projeto fornecer uma imagem própria, substitua core-image-minimal pelo nome real da receita, por exemplo silviolinux-image.

6. Testar e publicar

  • Teste a imagem em QEMU e no hardware-alvo.
  • Valide boot, rede, armazenamento, instalação e atualização de pacotes.
  • Gere SHA-256, assine os artefatos e publique notas de lançamento.
