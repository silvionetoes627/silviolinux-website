Guia de Compilação SilvioLinux

Siga os passos abaixo para compilar sua própria imagem do SilvioLinux utilizando a camada meta-silviolinux.

1. Requisitos do Sistema

Você precisará de uma máquina Linux (Ubuntu 22.04+ recomendado) com pelo menos 100GB de espaço livre e as dependências do Yocto instaladas.

sudo apt-get install gawk wget git diffstat unzip texinfo gcc build-essential chrpath socat cpio python3 python3-pip python3-pexpect xz-utils debianutils iputils-ping python3-git python3-jinja2 libegl1-mesa libsdl1.2-dev pylint xterm python3-subunit mesa-common-dev zstd liblz4-tool

2. Clonar os Repositórios

git clone -b scarthgap git://git.yoctoproject.org/poky
cd poky
git clone https://codeberg.org/SilvioLinux/meta-silviolinux

3. Configurar o Ambiente

source oe-init-build-env

4. Adicionar a Camada

bitbake-layers add-layer ../meta-silviolinux

5. Iniciar a Compilação

bitbake silviolinux-image-minimal

Aguarde a conclusão. O tempo depende do seu hardware.
