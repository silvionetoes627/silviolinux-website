Guia de compilação

Fluxo inicial para preparar o ambiente e compilar uma imagem Yocto/OpenEmbedded.

Os nomes de layers, máquinas e receitas abaixo são exemplos. Ajuste-os ao conteúdo real do repositório SilvioLinux e à versão do Yocto usada.

1. Obtenha o código

git clone -b aurora https://github.com/silvionetoes627/meta-silviolinux.git
cd meta-silviolinux

2. Prepare o ambiente

Instale as dependências recomendadas pela documentação da versão Yocto escolhida na sua distribuição hospedeira. Use uma máquina Linux x86_64 com espaço livre amplo.

3. Inicialize o ambiente de build

# Exemplo genérico — ajuste o caminho do poky e da layer
source poky/oe-init-build-env build

4. Configure a máquina e as layers

# Em conf/bblayers.conf, inclua as layers necessárias
# Em conf/local.conf, defina MACHINE e opções da imagem
bitbake-layers show-layers
bitbake-layers show-recipes

5. Compile a imagem

bitbake core-image-minimal

6. Valide a imagem

  • Confira os artefatos gerados em tmp/deploy/images/.
  • Teste primeiro em QEMU quando houver suporte à máquina configurada.
  • Depois valide boot, armazenamento, rede e consumo de memória no hardware-alvo.
