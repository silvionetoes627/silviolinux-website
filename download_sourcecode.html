Download do código-fonte

Estrutura inicial sugerida para organizar as camadas, configurações e receitas do SilvioLinux.

Repositório de exemplo

Substitua a URL abaixo pela URL pública definitiva quando o repositório oficial estiver publicado. Não há um clone remoto incluído neste pacote.

Clonar o projeto

git clone https://codeberg.org/SilvioRamalhoNeto/meta-silviolinux.git
cd meta-silviolinux

A URL é uma referência de projeto informada anteriormente e deve ser validada antes de publicar.

Estrutura sugerida

meta-silviolinux/
├── conf/
│   └── layer.conf
├── recipes-core/
├── recipes-kernel/
├── recipes-graphics/
└── README.md

Ferramentas

  • Git para controle de versão.
  • BitBake e OpenEmbedded fornecidos pelo ambiente Yocto.
  • bitbake-setup, quando disponível e compatível com a versão da distribuição Yocto utilizada.
  • Um host Linux com espaço em disco, memória e dependências suficientes para a compilação.
