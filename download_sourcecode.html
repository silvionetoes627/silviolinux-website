Obtenha o projeto

Download do código-fonte

Clone o repositório oficial e selecione a branch de desenvolvimento Aurora.

Clonar o repositório

git clone -b aurora https://github.com/silvionetoes627/meta-silviolinux.git

O comando baixa o código da branch aurora para o diretório meta-silviolinux.

Abrir repositório no GitHub
Antes de compilar: confira o README, os arquivos de configuração e as dependências indicadas no próprio repositório. O conteúdo e a branch podem mudar com o desenvolvimento.

Atualizar uma cópia existente

cd meta-silviolinux
git pull

Consulte o guia de compilação para conhecer o fluxo geral de trabalho.
