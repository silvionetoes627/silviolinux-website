Desenvolvimento

Download do código-fonte

Obtenha a meta-layer do SilvioLinux no GitHub e selecione a branch de desenvolvimento.

Clonar a branch Aurora

git clone -b aurora https://github.com/silvionetoes627/meta-silviolinux.git

Abrir repositório no GitHub

A branch aurora representa o ponto de partida indicado pelo projeto. Verifique no GitHub se ela existe e se está atualizada antes de clonar.

Pré-requisitos gerais

  • Git e ferramentas de compilação instalados em uma máquina hospedeira compatível.
  • Espaço em disco e memória suficientes para o build do Yocto/OpenEmbedded — normalmente muito superiores aos recursos do computador-alvo.
  • Conexão à internet para obter as camadas e o código-fonte.
