Requisitos para compilar

  • Uma distribuição Linux de desenvolvimento atualizada.
  • Git, Python 3, compilador C/C++, Make e ferramentas exigidas pelo Yocto.
  • Espaço em disco e memória suficientes para o build; compilar Yocto exige muito mais recursos do que executar uma imagem final.
  • Consulte sempre a documentação da versão do Yocto correspondente à branch utilizada.
Atenção: a branch aurora e o repositório são informados pelo projeto. Verifique no GitHub se a branch, as receitas e os manifests estão publicados antes de iniciar a compilação.
