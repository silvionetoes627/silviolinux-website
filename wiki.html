Comandos de Gravação no HD/SSD

Após baixar ou compilar a imagem, utilize os comandos abaixo para gravar o sistema em um disco físico.

Usando o comando DD (Linux/macOS)

Atenção: Substitua /dev/sdX pelo caminho correto do seu disco. O uso incorreto pode apagar seus dados.

sudo dd if=silviolinux-image.img of=/dev/sdX bs=4M status=progress conv=fsync

Verificando o disco

lsblk

Utilize este comando para identificar qual é o seu HD/SSD antes de iniciar a gravação.

Dicas de Pós-Instalação

  • Certifique-se de que a BIOS/UEFI está configurada para o modo correto.
  • O SilvioLinux utiliza o sistema de arquivos EXT4 por padrão na partição root.
