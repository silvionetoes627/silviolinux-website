Abrir downloads no GitHub Releases
Nenhum arquivo de imagem foi embutido neste pacote do site. Não há links fictícios para ISOs ou imagens ainda não publicadas.

Antes de instalar

  • Leia as notas da versão e confirme o modelo/arquitetura do equipamento.
  • Verifique o checksum SHA-256 publicado junto ao download.
  • Faça backup dos dados antes de gravar uma imagem em disco ou cartão.
