Download das imagens pré-compiladas

As imagens binárias devem ser publicadas na seção Releases do GitHub quando estiverem prontas para distribuição.

Imagens e pacotes

Consulte os arquivos anexados a cada versão. Verifique arquitetura, placa-alvo, checksum e notas de versão antes de gravar uma imagem em cartão ou unidade de armazenamento.

Abrir GitHub Releases
Nenhuma imagem pré-compilada é incluída neste pacote do site. Não considere uma imagem disponível até que ela esteja efetivamente anexada a uma release oficial do projeto.

Verificações recomendadas

  • Confirme se a imagem corresponde exatamente ao modelo da sua placa.
  • Leia as notas de instalação e os avisos de atualização.
  • Valide o checksum publicado junto ao arquivo, quando disponível.
  • Mantenha cópia de segurança dos dados antes de gravar a mídia.
