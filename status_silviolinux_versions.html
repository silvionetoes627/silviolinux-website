Roadmap de versões

Status das versões SilvioLinux

Calendário planejado das versões 1 a 70, com base Yocto, codename, requisitos de referência e fim de suporte.

Importante — projeção de longo prazo

As versões Yocto 7.0 a 24.1 e os lançamentos até 2063 são previsões fornecidas para este roadmap, não versões publicadas ou garantidas pelo Yocto Project. Confirme disponibilidade, compatibilidade de arquitetura e ciclo de suporte upstream antes de cada lançamento.

Regra adotada para completar a tabela: LTS = 4 anos; Non-LTS = 7 meses. As datas EOL são calculadas a partir da data de lançamento.

Política de suporte

Longo prazo

LTS · 48 meses

Correções de segurança e manutenção durante quatro anos, conforme capacidade de manutenção do projeto.

Curto prazo

Non-LTS · 7 meses

Janela proposta dentro do intervalo solicitado de seis a sete meses. Atualize para uma versão mais recente antes do EOL.

Idade de evolução

Desde Aurora

Tempo decorrido desde 30/06/2028, calculado para cada data de lançamento. É a idade do roadmap, não a idade de suporte.
