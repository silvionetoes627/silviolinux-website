Uma distribuição construída com Yocto

O Yocto Project oferece ferramentas para criar sistemas Linux personalizados para dispositivos e plataformas específicas. O SilvioLinux organiza suas receitas, camadas e configurações em torno desse ecossistema.

O mascote e a identidade visual desta página são ilustrações vetoriais originais do site. “Tux” é a mascote conhecida do Linux; esta arte é uma representação estilizada, não um logotipo oficial.
